# IEUM Chain v1.0.10.0 — 안전 종료와 snapshot 서명 안정화

## 버전과 포함 변경

- Cargo 버전: `1.0.10-0`
- 표시 버전 및 Git 태그: `1.0.10.0`, `v1.0.10.0`
- 종료 신호(SIGTERM·SIGINT)를 루프 전체에서 고정된 future 하나로 받아, 다른 분기 실행 중 들어온 신호도 놓치지 않습니다.
- 자동 업데이트 확인을 별도 스레드에서 실행해 네트워크가 먼저 내려가도 종료가 막히지 않습니다.
- snapshot 인증 서명에 실패해도 노드가 종료되지 않고 로그만 남깁니다.
- Chain ID, genesis, genesis hash, 프로토콜 버전과 합의 규칙은 변경하지 않습니다.

## 확인 방법

- 단일 노드에 SIGTERM, SIGINT를 각각 보내 즉시 `노드를 안전하게 종료합니다.` 로그와 함께 exit 0으로 끝나는 것을 확인했습니다.
- 배포 후 PC를 재부팅해 `docker inspect`의 ExitCode가 0(137 아님)인지 확인합니다. 재부팅 3회 동안 강제 종료 0건이면
  스마트 계약 설계 문서의 0단계 완료 기준을 만족합니다.

## 빌드와 배포

`v1.0.10.0` 태그 푸시 시 `chain-release.yml`이 세 번째 자리 변경(1.0.9 → 1.0.10)을 감지해
바이너리를 빌드하고 서명된 manifest와 GitHub Release를 게시합니다. 4노드는 `update-four-nodes.sh`로 갱신합니다.
