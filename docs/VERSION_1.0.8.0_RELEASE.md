# IEUM Chain v1.0.8.0 — 정식 바이너리 릴리스

## 버전과 포함 변경

- Cargo 버전: `1.0.8-0`
- 표시 버전 및 Git 태그: `1.0.8.0`, `v1.0.8.0`
- 이 릴리스는 v1.0.7.2의 재시작 후 과거 snapshot 체크포인트 서명 보호 변경을 포함합니다.
- Chain ID, genesis, genesis hash, 프로토콜 버전과 합의 규칙은 변경하지 않습니다.

## 빌드와 배포

릴리스 태그는 버전 파일을 반영한 커밋이 `main`에 병합되고, 필수 CI가 통과한 뒤 생성합니다.
`chain-release.yml`은 `v1.0.8.0` 태그에서 Linux, Windows, macOS 바이너리를 빌드하고
체크섬을 검증한 다음 서명된 업데이트 manifest와 GitHub Release를 게시합니다.

릴리스 빌드 정책은 major/minor/patch(앞의 세 자리)가 이전 태그와 다르면 바이너리 빌드를
수행합니다. 네 번째 문서 개정 자리만 달라질 때에는 기본적으로 바이너리를 생략합니다.
따라서 `v1.0.7.1`에서 `v1.0.8.0`으로 올리는 경우 정식 바이너리 빌드가 실행됩니다.

## 검증

버전 변경 PR과 `v1.0.8.0` 태그의 GitHub Actions 결과를 확인합니다.
운영 배포 전에는 게시된 파일의 체크섬과 노드의 실제 버전을 대조해야 합니다.
