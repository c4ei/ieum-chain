# IEUM Chain v0.21.4 운영 제네시스 식별자 고정

## 요청

- v0.21.3의 100 IEUM 테스트 잔액을 포함한 제네시스를 운영망 기준으로 확정한다.
- 월렛이 외부 v0.21.3 노드를 다른 제네시스로 거부하는 문제를 수정한다.

## 처리

- 체인 버전을 `0.21.4`로 올렸다.
- 운영 제네시스 SHA-256 식별자를 다음 값으로 회귀 테스트에 고정했다.

```text
657ce0cfeb8ad38d88a23711ec2664e5e1033aa8ffd5bb648a02ca0f348a9e1a
```

- 이 식별자는 Chain ID 21004, 기존 80,000 IEUM 배정, 테스트 주소
  `0x475e2f4e40Dbd34370e4fce61ddFF5Ff1F2eA817`의 100 IEUM 배정을 모두 포함한다.
- GossipSub에서 제안보다 먼저 도착한 정상 BFT 투표를 제한된 큐에 보관하고,
  제안 또는 단계 전환 직후 재처리하도록 수정했다.
- 한 서버 4노드 구성 시 대표 노드의 서명된 `config/update.json`을 node1~3에도
  설치하여 네 실행 파일이 모두 독립적으로 자동 업데이트되게 했다.

## 운영 주의

이미 이전 제네시스로 생성한 원장은 바이너리만 교체해도 새 제네시스로 바뀌지 않는다.
모든 운영 노드는 `ieum_networkIdentity`가 위 해시를 반환하는지 확인한 후 연결해야 한다.
