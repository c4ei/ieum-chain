# IEUM Chain 0.21.10

- 노드 보상 자산 지갑을 Ed25519에서 사용자 지갑과 같은 secp256k1 `0x` 주소로 수정
- 구형 노드 보상 keystore 자동 백업 및 새 주소 형식 이관
- 과거 합의 기록 호환을 위해 구형 64자리 보상 주소 검증은 유지
- `account new`, `account list`, `account send` 로컬 CLI 추가
- `reward address`, `reward send`를 0x 계정 서명 경로로 통일
- 받는 주소를 `0x` + 40자리로 명시 검증
- 사용자 문서에서 Ed25519 신원과 secp256k1 자산 주소의 역할을 분리해 설명

자동 일일 로또형 지급 계산기는 아직 합의 블록 생성 경로에 연결하지 않았습니다.
후보 집합 자체를 모든 검증자가 검증하는 프로토콜 없이 활성화하면 consensus split이
발생할 수 있어 이번 버전에서는 안전하게 비활성 상태를 유지합니다.
